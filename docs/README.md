# 문서 정리 안내

## 폴더 구조

- `docs/original/`
  - 초기 원본 문서 보관
- `docs/revisions/`
  - 원본을 바탕으로 수정한 개선본 문서 보관
- `docs/plans/`
  - 졸업작품 계획서와 참고 견본 보관
- `docs/logs/`
  - 작업 기록 보관
- `docs/ui/`
  - 화면 구성 및 UI 관련 문서 보관

## 정리 원칙

- 루트에는 실행 코드와 주요 폴더만 남긴다.
- 원본 문서와 수정 문서는 반드시 분리한다.
- 계획서와 참고 자료는 같은 폴더에 둔다.
- 작업 기록은 별도 보관해 수정 이력을 추적할 수 있게 한다.
