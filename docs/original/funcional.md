# 1. 세부 기능 명세서 (Functional Specification)

## 1.1 시스템 개요

본 시스템은 입력된 녹음 파일로부터 기타 성분을 분리하고, 음표 정보를 추출한 뒤 이를 기타 탭 및 MIDI 형태로 변환하여 사용자에게 제공하는 자동 채보 시스템이다.

---

## 1.2 기능 목록

## [F1] 오디오 업로드 및 전처리

### 기능 설명

사용자가 mp3/wav 파일을 업로드하면 시스템이 분석 가능한 형태로 변환한다.

### 입력

- mp3 / wav 파일

### 처리

- 샘플레이트 통일 (22050Hz 또는 44100Hz)
- mono 변환
- 길이 제한 (최대 60초)
- normalize

### 출력

- `input.wav`

### 예외 처리

- 지원하지 않는 포맷 → 오류 반환
- 파일 크기 초과 → 업로드 제한

---

## [F2] 기타 음원 분리

### 기능 설명

혼합 음원에서 기타 성분을 강조하여 추출한다.

### 입력

- `input.wav`

### 처리

- Demucs 기반 source separation
- guitar 또는 other stem 선택
- 필요 시 간단한 후처리 (노이즈 감소)

### 출력

- `guitar_separated.wav`

### 성능 기준

- 기타 성분이 청취 가능 수준으로 분리

---

## [F3] Onset Detection (음 시작 시점 검출)

### 기능 설명

기타 음이 시작되는 시점을 검출한다.

### 입력

- `guitar_separated.wav`

### 처리

- onset strength 계산
- peak detection

### 출력

```
[0.42,0.88,1.31, ...]
```

---

## [F4] Pitch Detection (음 높이 추정)

### 기능 설명

각 구간에서 발생한 음의 pitch를 추정한다.

### 입력

- 기타 음원

### 처리

- 방법 1: STFT / CQT 기반 피치 추정
- 방법 2: Basic Pitch 모델 활용
- 결과 통합 또는 선택

### 출력

- MIDI note number 리스트

---

## [F5] Note Event 생성

### 기능 설명

onset + pitch 정보를 결합하여 음표 이벤트 생성

### 출력 예시

```
[
  {"start":0.42, "end":0.74, "pitch":64},
  {"start":0.88, "end":1.10, "pitch":67}
]
```

---

## [F6] Quantization (박자 정렬)

### 기능 설명

불규칙한 연주 타이밍을 음악적 박자 단위로 정렬

### 처리

- BPM 추정
- beat grid 생성
- nearest grid로 snap

### 출력

- 정렬된 note event

---

## [F7] 줄/프렛 매핑 (핵심 기능)

### 기능 설명

MIDI 음을 기타 줄/프렛 위치로 변환

### 처리

1. 각 음의 가능한 위치 후보 생성
2. 비용 함수 정의
    - 프렛 이동 거리
    - 줄 이동
    - 포지션 유지
3. 동적 계획법(DP)으로 최적 경로 선택

### 출력

```
[
  {"string":3, "fret":2},
  {"string":4, "fret":2}
]
```

---

## [F8] 출력 생성

### 1) MIDI 생성

- pretty_midi 사용

### 2) MusicXML 생성

- music21 사용

### 3) Tab 생성

- ASCII tab 생성

예:

```
e|----------------|
B|----------------|
G|------2---------|
D|----2---2-------|
A|--0-------------|
E|----------------|
```

---

## [F9] 악보 렌더링

### 기능 설명

사용자가 볼 수 있도록 시각화

### 선택 기술

- VexFlow (웹)
- LilyPond (PDF)

---

## [F10] 결과 반환

### 출력

- 기타 분리 음원 재생
- MIDI 다운로드
- 탭 표시
- 악보 표시

---

# 2. 비기능 요구사항

- 처리 시간: 30초 이내 (60초 음원 기준)
- 지원 플랫폼: 웹 브라우저
- 정확도:
    - 단일 기타: 높은 정확도
    - 혼합 음원: 중간 수준
