# Stringsense 최종 발표 시나리오 - 사용자 흐름 중심

## 발표 방향

이번 발표에서는 내부 구현을 자세히 설명하기보다, 사용자가 서비스를 어떻게 사용하는지와 개발 중 어떤 문제를 발견해서 어떻게 수정했는지를 중심으로 설명한다.

발표 핵심 메시지는 다음과 같다.

- 기타 음원을 업로드하면 MIDI와 TAB 초안을 얻을 수 있다.
- 처음 계획보다 실제 시연에 필요한 기능 중심으로 화면을 정리했다.
- 결과가 이상하게 나오는 문제를 테스트하면서 여러 차례 수정했다.
- 최종적으로는 업로드, 결과 확인, 다운로드가 가능한 MVP 형태로 마무리했다.

---

## 1. 시작 멘트

안녕하세요. Stringsense 최종 발표를 시작하겠습니다.

Stringsense는 기타 연주 오디오 파일을 업로드하면 MIDI 파일과 기타 TAB 초안을 만들어주는 웹 서비스입니다.

완성된 악보를 바로 만들어주는 서비스라기보다는, 사용자가 채보를 시작할 때 참고할 수 있는 초안을 빠르게 만들어주는 것을 목표로 했습니다.

---

## 2. 사용자 입장에서의 문제

기타 채보를 직접 하려면 음원을 계속 반복해서 들어야 합니다.

어떤 음이 나오는지, 어느 박자에 나오는지, 기타에서는 어느 줄과 프렛으로 치면 되는지를 직접 판단해야 해서 시간이 많이 걸립니다.

특히 기타를 오래 치지 않은 사람은 음은 대충 알더라도 실제로 어느 줄에서 치면 자연스러운지 판단하기 어렵습니다.

그래서 이 프로젝트에서는 사용자가 음원을 업로드하면 자동으로 분석해서 MIDI와 TAB 초안을 보여주는 흐름을 만들었습니다.

---

## 3. 사용 흐름 설명

사용 흐름은 단순합니다.

먼저 사용자가 메인 화면에서 mp3 또는 wav 파일을 선택합니다.

그 다음 분석 시작 버튼을 누르면 서버에서 음원을 분석합니다.

분석이 끝나면 결과 화면으로 이동합니다.

결과 화면에서는 업로드한 원본 오디오를 다시 재생할 수 있고, 생성된 MIDI 파일을 다운로드할 수 있습니다.

또 화면 아래에는 자동으로 만들어진 TAB 미리보기가 표시됩니다.

TAB을 더 크게 보고 싶으면 TAB 상세 화면으로 이동해서 전체 내용을 확인할 수 있습니다.

마지막으로 TAB 다운로드 버튼을 누르면 `result_tab.txt` 파일로 저장할 수 있습니다.

즉 사용자는 파일 선택, 분석 시작, 결과 확인, 다운로드 순서로 사용할 수 있습니다.

---

## 4. 시연 멘트

이제 실제 화면으로 흐름을 보여드리겠습니다.

먼저 메인 화면에서 기타 샘플 파일을 선택합니다.

파일을 선택하면 선택한 파일명이 표시되고, 분석 시작 버튼을 누를 수 있습니다.

분석 시작을 누르면 서버가 오디오를 분석하고 결과를 생성합니다.

분석이 끝나면 결과 화면으로 이동합니다.

여기서 원본 오디오를 다시 들어볼 수 있고, MIDI 다운로드 버튼으로 생성된 MIDI 파일을 저장할 수 있습니다.

아래에는 TAB 미리보기가 표시됩니다.

TAB 크게 보기를 누르면 상세 화면으로 이동하고, 여기서 전체 TAB을 확인할 수 있습니다.

TAB 다운로드 버튼을 누르면 텍스트 파일로 저장됩니다.

이 흐름이 현재 완성한 MVP의 전체 사용자 흐름입니다.

---

## 5. 개발 중 발견한 문제 1 - 결과 화면에 없는 기능이 보임

개발 중 첫 번째로 수정한 문제는 결과 화면에 실제로 제공하지 않는 기능이 보였다는 점입니다.

초기 화면에는 기타 분리음원 재생과 다운로드 영역이 있었습니다.

하지만 현재 MVP에서는 기타 분리음원을 실제로 생성하지 않기 때문에, 사용자가 그 버튼을 눌러도 동작하지 않았습니다.

그래서 최종 발표용 화면에서는 분리음원 관련 영역을 제거했습니다.

대신 현재 실제로 동작하는 기능인 원본 오디오 재생, MIDI 다운로드, TAB 미리보기, TAB 다운로드만 남겼습니다.

이렇게 수정해서 사용자가 화면을 봤을 때 어떤 기능이 실제로 가능한지 더 명확하게 만들었습니다.

---

## 6. 개발 중 발견한 문제 2 - TAB 다운로드가 불안정함

두 번째 문제는 TAB 다운로드였습니다.

처음에는 서버에 생성된 `result_tab.txt` 파일 경로를 이용해 다운로드하도록 구성했습니다.

그런데 이전 분석 결과가 브라우저에 남아 있거나, 파일 경로가 갱신되지 않은 경우 다운로드가 안 되는 문제가 있었습니다.

그래서 다운로드 방식을 바꿨습니다.

이제는 화면에 표시된 TAB 내용을 브라우저에서 바로 텍스트 파일로 만들어 다운로드합니다.

이 방식으로 바꾸면 서버 파일 경로에 문제가 있어도, 사용자가 보고 있는 TAB 내용을 그대로 `result_tab.txt`로 저장할 수 있습니다.

---

## 7. 개발 중 발견한 문제 3 - MIDI 결과가 이상하게 나옴

세 번째 문제는 MIDI 결과 품질이었습니다.

초기에는 직접 오디오 신호를 분석해서 음을 추정하는 방식으로 구현했습니다.

하지만 실제 기타 샘플을 넣어보니, 한 번만 친 음이 두 번으로 나뉘어 들리거나, 특정 음이 빠지거나, 실제로 치지 않은 높은 음이 잡히는 문제가 있었습니다.

기타 소리는 배음과 잔향이 많아서 단순한 방식으로는 정확하게 음을 잡기 어려웠습니다.

그래서 여러 번 감도를 조정해봤지만, 샘플에 따라 결과가 계속 달라졌습니다.

최종적으로는 Basic Pitch를 사용하도록 바꿨습니다.

이 변경으로 직접 튜닝하던 방식보다 더 안정적으로 note 결과를 얻을 수 있게 했습니다.

---

## 8. 개발 중 발견한 문제 4 - TAB 운지가 어색함

네 번째 문제는 TAB 결과가 실제 연주 관점에서 어색하다는 점이었습니다.

처음에는 낮은 프렛을 우선으로 선택하게 했습니다.

그런데 실제로 결과를 보니 낮은 프렛만 고르는 방식이 항상 자연스럽지는 않았습니다.

예를 들어 같은 줄에서 멀리 떨어진 프렛으로 이동하는 것보다, 다른 줄의 비슷한 프렛으로 이동하는 편이 손 위치가 덜 움직이고 더 자연스러운 경우가 있습니다.

그래서 줄과 프렛을 선택하는 기준을 수정했습니다.

이제는 단순히 낮은 프렛을 고르는 것이 아니라, 이전 음에서 손이 얼마나 이동해야 하는지를 더 중요하게 보도록 바꿨습니다.

같은 줄에서 멀리 움직이는 경우는 줄이고, 다른 줄이라도 비슷한 프렛이면 그쪽을 선택하도록 조정했습니다.

---

## 9. 최종적으로 한 일 정리

최종적으로 한 일은 다음과 같습니다.

첫 번째, 오디오 파일 업로드부터 결과 화면까지 이어지는 웹 흐름을 만들었습니다.

두 번째, 분석 결과로 MIDI 파일을 생성하고 다운로드할 수 있게 했습니다.

세 번째, 기타 TAB 초안을 화면에 표시하고 텍스트 파일로 저장할 수 있게 했습니다.

네 번째, 실제 동작하지 않는 분리음원 기능은 화면에서 제거했습니다.

다섯 번째, MIDI 결과가 불안정한 문제를 해결하기 위해 Basic Pitch 기반 분석 방식으로 바꿨습니다.

여섯 번째, TAB에서 손이 너무 왔다 갔다 하지 않도록 줄과 프렛 선택 기준을 수정했습니다.

---

## 10. 현재 한계

현재 결과는 완성 악보가 아니라 초안입니다.

입력 음원의 품질이나 연주 방식에 따라 MIDI와 TAB 결과가 완벽하지 않을 수 있습니다.

또한 현재는 단일 기타나 기타 소리가 뚜렷한 샘플을 기준으로 동작합니다.

반주가 섞인 음원이나 복잡한 코드 연주에서는 정확도가 떨어질 수 있습니다.

하지만 이번 프로젝트의 목표는 자동 채보의 첫 단계를 웹에서 경험할 수 있게 만드는 것이었고, 업로드부터 결과 확인과 다운로드까지 이어지는 MVP 흐름은 완성했습니다.

---

## 11. 마무리 멘트

정리하면, Stringsense는 사용자가 기타 음원을 업로드하면 MIDI와 TAB 초안을 자동으로 생성해주는 웹 서비스입니다.

개발 과정에서 실제로 동작하지 않는 화면 요소를 제거하고, 다운로드 문제와 MIDI 결과 문제, TAB 운지 문제를 수정하면서 최종 시연 가능한 형태로 정리했습니다.

이상으로 발표를 마치겠습니다. 감사합니다.
