# 오늘 발표 내용 정리

## 1. 작품명

자동 기타 채보 웹서비스

## 2. 발표 주제

오디오 파일에서 기타 연주 정보를 추출하여 MIDI와 기타 탭 초안을 자동 생성하는 웹서비스의 기획 방향, 처리 흐름, 화면 구성, 그리고 현재까지의 진행 상황을 발표하였다.

## 3. 작품 개요

기존 기타 채보 작업은 사용자가 음원을 반복 청취하면서 음 높이, 박자, 운지를 직접 추정해야 하므로 시간이 많이 소요되고 숙련도 의존성이 크다. 또한 일반적인 MIDI 변환 도구는 기타 전용 줄과 프렛 기반 탭 출력까지 제공하지 못하는 경우가 많다.

본 작품은 사용자가 오디오 파일을 업로드하면 분석 파이프라인을 자동으로 수행하여 기타 분리 음원, MIDI 파일, 기타 탭 초안을 제공하는 것을 목표로 한다. 이를 통해 사용자가 완성된 악보가 아니라 수정 가능한 초안을 빠르게 얻을 수 있도록 하는 데 목적이 있다.

## 4. 작품 목표

- 오디오 파일 업로드
- 처리 상태 확인
- 기타 분리 음원 재생
- MIDI 파일 다운로드
- ASCII 기타 탭 초안 확인
- 결과 화면을 통한 미리보기 및 저장 기능 제공

초기 목표는 단일 기타 또는 기타가 지배적으로 들리는 음원에서 `result.mid`와 `result_tab.txt`를 생성하는 것이다.

## 5. 주요 처리 흐름

전체 시스템은 다음과 같은 흐름으로 구성된다.

1. 오디오 파일 업로드
2. 입력 검증 및 전처리
3. 필요 시 기타 분리
4. onset 검출
5. pitch 추정
6. note event 생성
7. quantization
8. 줄/프렛 매핑
9. MIDI 및 탭 출력

## 6. 주요 기능

- 파일 업로드
- 분석 시작
- 처리 상태 확인
- 원본 음원 재생
- 기타 분리 음원 재생
- MIDI 다운로드
- 탭 보기
- 새 파일 다시 분석하기

## 7. 화면 구성
### 화면 01. 메인 업로드 화면

- 파일 선택 또는 드래그 앤 드롭 지원
- 샘플 파일 불러오기 가능
- 분석 시작 버튼 제공

### 화면 02. 처리 상태 화면

- 분석 중 상태를 스피너와 단계 표시로 제공
- 현재 처리 진행 여부 확인 가능

### 화면 03. 결과 화면

- 원본 음원 재생
- 기타 분리 음원 재생
- MIDI 파일 다운로드
- 탭 미리보기 제공

### 화면 04. 탭 상세 보기 화면

- 생성된 탭 초안을 큰 화면에서 확인
- 결과 화면으로 돌아가기
- 파일 저장

## 8. 이번 주 진행 내용

이번 주에는 사용자 관점에서 실제 서비스처럼 보이는 프론트 화면 시안을 구현하였다. 업로드 화면, 처리 상태 화면, 결과 화면, 탭 상세 화면을 구성하고, 각 화면이 자연스럽게 연결되도록 정리하였다.

또한 결과 화면에서는 사용자가 바로 이해할 수 있도록 원본 음원 재생, 기타 분리 음원 재생, MIDI 다운로드, 탭 미리보기와 같은 기능 중심으로 화면을 개선하였다. 내부 알고리즘 지표나 불필요한 기술 정보는 최소화하고, 실제 사용자 행동 흐름이 잘 드러나도록 화면을 수정하였다.

추가로 프로젝트 문서를 `docs` 폴더 아래로 정리하고, 원본 문서, 수정 문서, 계획서, 작업 기록을 분리하여 관리할 수 있도록 정리하였다.
