# 주간보고서 5주차 수정안

## 제목

- 캡스톤디자인 주간보고서
- (5주차: 2026.4.02)

## 1. 보고자

- 이동윤(202384026)

## 2. 작품명

- Stringsense - AI 기반 기타 자동 채보 웹서비스

## 3. 작품 설명

- 오디오 파일을 업로드하면 기타 연주 정보를 분석하여 기타 분리 음원, MIDI 파일, 기타 탭 초안을 제공하는 웹 서비스를 개발한다. 사용자는 웹 화면에서 음원을 업로드하고 처리 상태를 확인한 뒤, 결과 화면에서 음원 재생, 파일 다운로드, 탭 확인을 할 수 있다. 본 작품은 기타 채보 과정을 단순화하여 사용자가 수정 가능한 초안을 빠르게 얻을 수 있도록 하는 것을 목표로 한다.

## 4. 주요기능 및 작업 내용

- 오디오 파일 업로드 및 샘플 불러오기
- 분석 진행 상태 화면 구성
- 결과 화면에서 원본 음원 및 기타 분리 음원 재생
- MIDI 파일 다운로드
- 기타 탭 미리보기 및 탭 상세 화면 제공
- 프로젝트 문서 구조 정리 및 계획서 수정

## 5. 개발 환경

- Frontend: HTML, CSS, JavaScript
- Audio/AI: librosa, torchaudio, Demucs, pretty_midi
- 문서 작업: Markdown
- 버전관리: Git, GitHub
- 개발 도구: VS Code

## 6. 진행사항

### 4주차 작업 내용

- 프로젝트 구조를 정리하고 문서를 원본, 수정본, 계획서, 작업 기록으로 분리하여 관리할 수 있도록 구성하였다. 또한 프로젝트의 방향과 기능을 명세서 형태로 정리하여 이후 구현 기준을 마련하였다. 5주차에는 실제 서비스 화면처럼 보이는 프론트 시안을 구현하고, 사용자 흐름에 맞게 화면 구성을 정리할 예정이다.

### 5주차 작업 내용

- 이번 주에는 사용자 관점에서 실제 서비스처럼 보이는 프론트 화면 시안을 구현하였다. `frontend` 폴더에 새 분석 시작 화면, 분석 진행 중 화면, 결과 화면, 탭 상세 화면을 구성하고, 각 화면이 서로 자연스럽게 연결되도록 정리하였다.
- 업로드 화면에서는 파일 선택, 드래그 앤 드롭, 샘플 불러오기, 분석 시작 기능이 보이도록 구성하였다. 처리 중 화면에서는 현재 분석이 진행되고 있다는 점을 직관적으로 보여주도록 로딩 상태와 단계 표시를 배치하였다.
- 결과 화면에서는 원본 음원, 기타 분리 음원, MIDI 다운로드, 탭 미리보기를 중심으로 배치하여 사용자가 결과를 바로 확인할 수 있게 하였다. 또한 탭 상세 화면에서는 생성된 기타 탭 초안을 크게 보고 저장하거나 결과 화면으로 돌아갈 수 있도록 구성하였다.
- 화면 구성 과정에서 일반 사용자에게 불필요한 내부 지표나 기술 정보를 줄이고, 업로드, 재생, 다운로드, 되돌아가기와 같은 실제 사용자 행동 중심으로 UI를 수정하였다. 이를 통해 발표 자료에 사용할 수 있는 프론트 시안을 완성하였다.

### 6주차에 진행할 내용

- FastAPI 기반 백엔드 초기 구조 구현
- 서버가 정상적으로 실행되는지 확인
- 기본 라우트 및 응답 흐름 구성
- 이후 업로드 기능 연결을 위한 백엔드 구조 정리
