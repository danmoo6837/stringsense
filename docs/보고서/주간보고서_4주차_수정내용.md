### 1. 보고자

### 2. 작품명

- Stringsense - AI 기반 기타 자동 채보 웹서비스

### 3. 작품 설명

- 오디오 파일을 업로드하면 기타 연주 정보를 분석하여 기타 분리 음원, MIDI 파일, 기타 탭 초안을 제공하는 웹 서비스를 개발한다. 본 작품은 기타 채보 과정을 자동화하여 사용자가 수정 가능한 초안을 빠르게 얻을 수 있도록 하는 것을 목표로 한다. 초기 단계에서는 전체 서비스 구현보다 프로젝트 구조 정리, 기술 조사, 업로드 및 분석 파이프라인 설계에 중점을 둔다.

### 4. 주요기능 및 작업 내용

- 오디오 파일 업로드 (`mp3`, `wav`)
- 기타 음원 분리
- 오디오 분석 기반 MIDI 생성
- 기타 탭 초안 생성
- 프로젝트 구조 및 기능 명세 정리

### 5. 개발 환경

- Frontend: 추후 웹 화면 구현 예정
- Audio/AI: librosa, torchaudio, Demucs, pretty_midi
- 버전관리: Git, GitHub
- 개발 도구: VS Code

### 6. 진행사항

#### 3주차 작업 내용

- 프로젝트 주제를 자동 기타 채보 웹서비스로 확정하고, 전체 기능 흐름을 정리하였다. 또한 현재 디렉터리에 프로젝트 프레임워크 문서, 기능 명세서, 디렉터리 구조 문서와 같은 기초 문서를 작성하여 작품의 목표, 주요 기능, 범위, 구조를 정의하였다. 이를 통해 이후 구현 단계에서 어떤 기능을 우선적으로 개발할지 기준을 세웠다. 4주차에는 이 문서 내용을 바탕으로 실제 프로젝트 폴더 구조를 정리할 예정이다.

#### 4주차 작업 내용

- 3주차에 작성한 문서 내용을 바탕으로 현재 프로젝트 구조를 실제 디렉터리 형태로 정리하였다. `frontend`, `bakend`, `docs`를 중심으로 폴더를 구분하고, 문서 또한 원본 문서, 수정 문서, 계획서, 작업 기록으로 나누어 관리할 수 있도록 구성하였다. 또한 프로젝트에서 사용할 오디오 분석 관련 라이브러리와 전체 개발 흐름을 다시 점검하면서 이후 구현 순서를 정리하였다. 다음 주에는 업로드 기능과 화면 구성을 중심으로 프론트엔드 시안을 구체화할 예정이다.
