# 주간보고서 6주차

## 제목

- 캡스톤디자인 주간보고서
- (6주차: 2026.4.28)

## 1. 보고자

- 이동윤(202384026)

## 2. 작품명

- Stringsense - AI 기반 기타 자동 채보 웹서비스

## 3. 작품 설명

- 오디오 파일을 업로드하면 기타 연주 정보를 분석하여 기타 분리 음원, MIDI 파일, 기타 탭 초안을 제공하는 웹 서비스를 개발한다. 사용자는 웹 화면에서 음원을 업로드하고 처리 상태를 확인한 뒤, 결과 화면에서 음원 재생, 파일 다운로드, 탭 확인을 할 수 있다. 본 작품은 기타 채보 과정을 단순화하여 사용자가 수정 가능한 초안을 빠르게 얻을 수 있도록 하는 것을 목표로 한다.

## 4. 주요기능 및 작업 내용

- FastAPI 기반 백엔드 서버 초기 구현 및 실행 환경 구성
- 오디오 파일 업로드 API 구현 및 저장 경로 구성
- librosa CQT 기반 음정 추출 서비스 구현
- MIDI 파일 생성 및 ASCII 기타 탭 렌더링 서비스 구현
- 전체 분석 파이프라인 연결 (전처리 → 음정 추출 → 결과 생성)
- 프론트엔드와 백엔드 API 연결 (fetch 기반 비동기 통신)

## 5. 개발 환경

- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI, uvicorn, Python
- Audio/AI: librosa, pretty_midi
- 문서 작업: Markdown
- 버전관리: Git, GitHub
- 개발 도구: VS Code

## 6. 진행사항

### 5주차 작업 내용

- 사용자 관점에서 실제 서비스처럼 보이는 프론트 화면 시안을 구현하였다. `frontend` 폴더에 분석 시작 화면, 분석 진행 중 화면, 결과 화면, 탭 상세 화면을 구성하고 각 화면이 자연스럽게 연결되도록 정리하였다. 불필요한 기술 지표를 줄이고 업로드, 재생, 다운로드 등 실제 사용자 행동 중심으로 UI를 수정하여 발표 자료에 활용 가능한 프론트 시안을 완성하였다.

### 6주차 작업 내용

- 이번 주에는 FastAPI 기반 백엔드 초기 구조를 구현하고 서버가 정상적으로 실행되는지 확인하였다. `backend/app/main.py`에 FastAPI 앱 진입점을 작성하고 CORS 설정 및 프론트엔드 정적 파일 서빙을 구성하였다. 또한 Pydantic 기반 응답 스키마와 `POST /analyze`, `GET /files/{job_id}/{filename}` 등 핵심 라우트를 구현하였다.
- 오디오 처리 서비스로는 librosa 기반 전처리 모듈을 작성하여 업로드된 파일을 22050Hz mono로 정규화하고 60초 이내로 제한하도록 구성하였다. 음정 추출 서비스는 CQT(Constant-Q Transform)와 onset detection을 활용하여 음표 이벤트 목록을 반환하도록 구현하였으며, 이를 통해 외부 AI 모델 의존 없이 직접 구현한 음정 추출 방식을 확보하였다.
- 결과 생성 측면에서는 추출된 음표 이벤트를 pretty_midi를 통해 MIDI 파일로 변환하고, ASCII 형식의 기타 탭 텍스트로 렌더링하는 서비스를 구현하였다. 이후 전처리, 음정 추출, 결과 생성 단계를 하나로 연결하는 파이프라인 모듈을 작성하여 전체 분석 흐름이 하나의 API 호출로 처리되도록 구성하였다.
- 프론트엔드에서는 `app.js`에 실제 API 호출 로직을 추가하여 분석 시작 버튼을 클릭하면 `POST /analyze`로 파일을 전송하고 결과를 localStorage에 저장한 뒤 결과 화면으로 이동하도록 구현하였다. 또한 `result.html`과 `tab.html`에 id를 추가하여 JS 데이터 바인딩을 통해 실제 분석 결과가 화면에 표시되도록 연결하였다.

### 7주차에 진행할 내용

- 실제 wav/mp3 파일을 이용한 엔드투엔드 테스트 수행
- CQT 기반 음정 추출 정확도 확인 및 파라미터 조정
- 기타 음역 범위 밖 음표 처리 예외 케이스 점검
- 프론트-백엔드 연동 흐름 전체 검증
