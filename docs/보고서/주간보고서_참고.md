참고
-	작업 내용이 구체적이고 상세할수록 좋습니다.
-	형식적으로 작성하지 말고 자신의 작업을 잘 분석하여 구체적으로 작업을 계획한다.
-	매주 진행된 내용을 보고서로 작성하여 주간보고서로 제출한다.
-	지난 학기와 연속인 경우 첫 주는 지금까지 진행된 작업 내용을 요약하여 보고한다.
-	팀으로 작품을 할지라도 모든 팀원은 자신이 진행한 작업 내용을 보고한다.
-	진행 사항은 매주 작업 내용을 추가하고, 다음 주 작업 내용도 기술한다.
-	진행될수록 작업한 내용이 점차 쌓여 최종보고서에서 활용할 수 있도록 정리한다.
-		계획대비진도표에서 각 작업별 윗부분(붉은색) 계획된 일정이고, 아랫부분(푸른색)은 실제로 진행된 진도를 의미한다.
