# 화면 기능 정리

## 화면 01. 메인 업로드 화면

- 사용자는 `mp3`, `wav` 파일을 업로드할 수 있다.
- 사용자는 샘플 음원을 불러와 데모를 바로 실행할 수 있다.
- 사용자는 분석 시작 버튼을 눌러 처리 단계로 이동할 수 있다.

## 화면 02. 분석 진행 및 결과 화면

- 사용자는 현재 분석 단계가 어디까지 진행됐는지 확인할 수 있다.
- 사용자는 원본 음원과 기타 분리 음원을 비교 재생할 수 있다.
- 사용자는 MIDI 파일을 다운로드할 수 있다.
- 사용자는 탭 미리보기를 확인하고 상세 화면으로 이동할 수 있다.

## 화면 03. 탭 상세 보기 화면

- 사용자는 생성된 ASCII 탭을 크게 확인할 수 있다.
- 사용자는 줄/프렛 정보를 통해 실제 연주 위치를 파악할 수 있다.
- 사용자는 결과 파일을 저장하거나 다시 분석 화면으로 돌아갈 수 있다.

## PPT 강조 포인트

- 단순 파일 업로드 화면이 아니라 분석 결과와 최종 산출물까지 이어지는 흐름이 보인다.
- 결과물은 `기타 분리 음원`, `MIDI`, `기타 탭 초안`으로 명확하게 제시된다.
- 사용자가 실제로 무엇을 클릭하고 무엇을 받는지 화면 기준으로 설명할 수 있다.
