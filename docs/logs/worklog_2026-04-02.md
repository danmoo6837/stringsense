- 중간 산출물 파일명이 문서마다 다르게 쓰여 있었음
- 기능 범위와 프로젝트 범위가 문서마다 다르게 읽힘

### 기능 명세의 모호함

- 성능 기준이 정성적으로만 적혀 있었음
- 실패 처리, 테스트 기준, 입력 제한이 충분히 명시되지 않았음

### 파일명 문제
