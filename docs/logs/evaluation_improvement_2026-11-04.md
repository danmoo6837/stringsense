# librosa 전사 개선 및 solo 재평가

실제 Docker 백엔드 `/analyze`에서 생성한 MIDI를 동일한 solo 180곡의 정답 JAMS와 비교했다. 시작 ±50ms, 음높이 ±50센트 기준을 유지했다. 실패 0곡.

| micro 지표 | 변경 전 | 변경 후 |
|---|---:|---:|
| 정밀도 | 41.58% | 64.68% |
| 재현율 | 27.18% | 76.04% |
| 시작+음높이 F1 | 32.87% | 69.90% |
| 종료 포함 F1 | 13.94% | 50.55% |

정답 16,861개 중 매칭 12,821개, 오검출 7,001개, 누락 4,040개. 누락은 크게 줄었지만 오검출 개수는 이전 6,440개보다 늘어 추가 개선이 필요하다.

## 변경

- onset 검출의 backtrack을 끄고 delta 0.12→0.07, wait 3→1로 조정.
- 최소 onset 간격 140ms→50ms, 최소 음 길이 60ms→40ms.
- 별도 공격점에서 시작한 같은 음을 합치지 않아 반복음 보존.
- CQT 계산과 주파수 해석 모두 C2를 기준으로 통일. 이전에는 계산 기본값과 해석 기준이 달랐다.
- pYIN 구간 대표 음높이를 중앙값 대신 신뢰도 가중 최빈값으로 선택.
- 종료는 다음 onset을 상한으로 두고 기본음 CQT 에너지가 최대의 15% 아래로 3프레임 연속 내려가는 지점을 추정. 마지막 음은 오디오 끝까지 추적하며, 이전의 고정 최대 길이/마지막 음 0.5초 제한은 사용하지 않음.

각 변경의 독립적 효과를 분리한 실험은 수행하지 않았다. 종료 에너지 임계값은 초기 휴리스틱이며 정식 다성 전사나 독립 테스트셋 성능을 의미하지 않는다. 개선 방향을 판단한 동일 데이터셋에서 재평가했으므로 일반화 성능은 별도 데이터로 확인해야 한다.
